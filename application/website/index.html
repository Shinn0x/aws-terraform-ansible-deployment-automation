About this project

A static website on AWS, built and deployed entirely as code.

  • TerraformCreates the network, firewall, EC2 instance, Elastic IP and DNS record.
  • AnsibleInstalls nginx, sets up HTTPS, publishes this page and checks it works.
  • nginxServes this page from /var/www/html.

Edit a file, rerun the playbook, and the site updates. Built by Shin.
